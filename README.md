## Overview

A 100% client-side single-page app that analyses CVs with the Gemini API. Import a CV, get a scored review with strengths and weaknesses, improve the content, export an optimised PDF and browse local and international job listings. There is no backend: the API key lives in sessionStorage and analysis happens in the browser.

## Highlights

- AI CV scoring with detailed strengths and weaknesses
- Content-improvement suggestions
- Optimised PDF export
- Local and international job matching
- Zero-backend architecture; API key kept in sessionStorage

## Getting started

**Prerequisites:** A modern browser and a Gemini API key.

```bash
# open index.html directly, or serve the folder:
npx serve .
# then paste your Gemini API key in the app
```
